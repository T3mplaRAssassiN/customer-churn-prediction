# 📊 Customer Churn Prediction (پیش‌بینی ریزش مشتریان)

این پروژه یک سیستم End-to-End یادگیری ماشین برای پیش‌بینی احتمال ریزش مشتریان یک شرکت مخابراتی است.

## 🎯 هدف پروژه
شناسایی مشتریانی که احتمال می‌رود خدمات را ترک کنند، تا شرکت بتواند با ارائه پیشنهادهای ویژه از ریزش آن‌ها جلوگیری کند.

## 📁 ساختار پروژه
- `notebooks/`: شامل تحلیل داده‌های اکتشافی (EDA) و مدل‌سازی.
- `app/`: داشبورد تعاملی ساخته‌شده با Streamlit.
- `models/`: مدل آموزش‌دیده (Random Forest with Class Weights).
- `data/`: داده‌های خام و پردازش‌شده.

## 🛠️ تکنولوژی‌های استفاده‌شده
- Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn)
- Streamlit (برای داشبورد)
- Joblib (برای ذخیره مدل)
